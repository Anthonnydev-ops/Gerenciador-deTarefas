# 📋 Gerenciador de Tarefas

Um sistema simples de gerenciamento de tarefas desenvolvido em **Python** com o objetivo de praticar conceitos fundamentais da linguagem, como funções, loops, variáveis, listas e estruturas condicionais.

O programa funciona através do terminal e permite ao usuário gerenciar suas tarefas de forma rápida e intuitiva.

---

## 🚀 Funcionalidades

- ➕ Adicionar novas tarefas
- 📄 Visualizar tarefas cadastradas
- ✏️ Atualizar tarefas existentes
- ✅ Marcar tarefas como concluídas
- 🗑️ Excluir tarefas concluídas
- 🚪 Encerrar o programa

---

## 🛠️ Tecnologias Utilizadas

- Python 3

---

## 📚 Conceitos Aplicados

Este projeto foi desenvolvido para reforçar conhecimentos básicos de programação utilizando:

- Funções
- Loops (`while`)
- Estruturas condicionais (`if`, `elif`, `else`)
- Variáveis
- Listas
- Manipulação de strings
- Entrada e saída de dados (`input` e `print`)
